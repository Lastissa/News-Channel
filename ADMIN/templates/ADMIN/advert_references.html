How the reference works

The reference is 16 characters: the first five letters of the account email, the issue date, then five random characters. It stays the same when a plan is renewed.

Pausing or ending a reference stops it showing in the home rail. It does not delete the advertiser's view and click history.

An optional advert subdomain gives one campaign a branded URL, such as newads.{{ ads_base_host }}. Every advert must use a different subdomain.
