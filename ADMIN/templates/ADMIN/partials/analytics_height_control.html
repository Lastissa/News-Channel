{% comment %} Per-chart height control, shared by every chart card. Each chart gets its own height and its own unit (px / rem / vh), so a wide bar chart and a tall trend line no longer share one fixed plot height. The value is remembered per admin in localStorage (keyed by `data-chart-height-id`, which each card sets uniquely), so it survives navigation and reloads with no migration and no SiteSettings change. analytics.js reads the control, stores the choice, and applies it to the card's [data-chart] as a CSS variable; with JS off the control simply does nothing and the chart keeps its default adaptive height. `height_id` must be unique per chart, and `height_default` is the initial value written into the input. {% endcomment %}
