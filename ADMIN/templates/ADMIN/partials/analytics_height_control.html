{% comment %} Per-chart height control, shared by every chart card. The height is expressed as a SHARE OF THE CHART'S OWN HEIGHT, as a percent: 100 is the chart at its full natural height, 50 is half of it, 150 is half again taller. Because it is relative to the chart itself, the same value reads as the same shape on a phone and on a wide desktop, and a chart never has to be told about pixels, rem or viewport units. The value is remembered per admin in localStorage (keyed by `data-chart-height-id`, which each card sets uniquely), so it survives navigation and reloads with no migration and no SiteSettings change. analytics.js reads the control and scales the chart's natural height by the percentage; with JS off the control simply does nothing and the chart keeps its default height. `height_id` must be unique per chart. {% endcomment %}
