{% comment %} The lytics chamber strip, shared by every lytics page. The chambers used to be reachable only by walking back to the PANEL and picking the next one. This rail puts them all on every lytics page, with the current chamber marked aria-current="page", so one tap moves between them without a detour. Staff was removed -- it duplicated Author, which is the real people-facing chamber now. `active_chamber` is the slug of the chamber that owns the page (passed by its view); every link carries its own slug so the comparison is one step. Icons come from the page's own sprite (`i-user` / `i-chart` / `i-image`), which each lytics shell already ships. {% endcomment %}
