{% comment %} The shared bucket / range / custom-date controls, used by every chart that measures something over time. One partial so the charts that own these controls cannot drift apart: the Trends card, the Members-over-time card, the Story lytics publishing chart, the per-story performance chart and the per-category charts all measure to the same window, and they must offer the same windows. The range menu carries two scales. A day scale window ("Last 30 days") asked of an hourly bucket would ask for 720 points, which reads as a smear, so the menu swaps to the hour scale when the bucket is 12 hours or 1 hour.
