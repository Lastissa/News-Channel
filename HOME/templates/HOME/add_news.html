Formatting guide

None of this is required. A story written as plain paragraphs is fine.

Before you publish

  1. Your first paragraph must not copy the headline. If the two are 90% or more alike, the story will be rejected.
  2. Do not begin the content with a # heading that repeats the headline. The headline already appears above the story.
  3. The story needs real content, not just a heading or filler. A very short story may trigger a warning; you can edit it or confirm that it contains enough information to post.
  4. Use headings for real sections. Empty ones like # or ## are rejected.
  5. Do not use lines of symbols such as ------ or ====== or ******. Leave a blank line instead.
  6. Start with a normal paragraph where possible. Markdown headings are allowed for real sections, but do not repeat the main headline at the start of the story.

Layout

Blank line
Starts a new paragraph
# Text
Subheading
## Text
Smaller subheading
### Text
Smallest subheading
* Text
Bullet point
1. Text
Numbered point (then 2., 3. and so on)

Text style

**text**
Bold
__text__
Italic
https://...
Becomes a clickable link by itself

Images and files each on its own line

imgl URL description
Image on the left, text wraps around it
imgr URL description
Image on the right, text wraps around it
imgc URL description
Image in the centre on its own line
filel URL link text
Download link for a file

The description is optional for images. Without it, the file name from the URL is used.
